# FitGirl Repacks 网格

把 [FitGirl Repacks](https://fitgirl-repacks.site/) 的更新列表，改造成 Steam 风格的高密度网格页面：
一屏看几十款游戏，鼠标悬浮看截图/预告片，数据存在本地，直接读写 `games.json`。

原站是单列长文，看更新要滚很久。这个工具解决的就是这个问题。

---

## 系统要求

| 项目     | 要求 |
| -------- | ------------------ |
| 操作系统 | Windows 10 / 11（`start.bat` 是 Windows 批处理） |
| Python   | 3.7 及以上，安装时勾选 **Add Python to PATH** |
| 浏览器   | **Chrome 86+** 或 **Edge 86+**（必须 Chromium 内核） |

**Firefox 和 Safari 不能用**，因为页面依赖 `File System Access API` 直接读写本地文件，只有 Chromium 内核支持。

---

## 快速开始

1. 下载本项目的压缩包，解压到任意目录（路径尽量简短，避免特殊字符，空格可以）
2. 双击 **`start.bat`**
3. 脚本会自动：
   - 检查 Python 是否存在
   - **将已有的 `games.json` 备份为 `games.json.bak`**（覆盖式，只保留一份）
   - 检查 8000 端口是否被占用
   - 自动查找 Chrome / Edge 并打开 `http://localhost:8000/`
   - 启动本地 HTTP 服务
4. 浏览器打开后，按下方“首次使用”操作

**停止服务**：在 `start.bat` 的黑色窗口按 `Ctrl+C`，或直接关闭窗口。

---

## 首次使用

页面会显示一个遮罩，要求绑定数据文件。点击 **“📂 绑定 games.json”**：

- **如果你已经有 `games.json`**（比如从别处拷来的）：在弹出的“打开文件”对话框里选中它
- **如果你还没有**：在“打开文件”对话框里直接点“取消”，会紧接着弹出“保存文件”对话框，默认文件名 `games.json`，选择保存位置即可

绑定成功后：

- 数据会立即写入你选择的 `games.json`
- 如果文件里没有数据，会自动从 FitGirl 站点拉取最新 100 篇
- 之后所有操作（同步、隐藏、收藏、翻译标题）都会**自动写入这个 `games.json`**

---

## 每次打开页面

由于浏览器的安全策略（File System Access API 的硬限制），**每次新开页面都需要点一次“✅ 继续使用”来恢复文件读写权限**。

这是 Chrome/Edge 的限制，不是本工具的 bug。点击后：

- 页面从 `games.json` 读取数据
- 如果距上次检查超过 12 小时，会自动拉取新帖子
- 之后所有操作自动落盘，无需再操作

**请只开一个标签页使用**。同时打开两个标签页绑定同一个 `games.json`，两个页面的写入会互相覆盖，导致数据异常。

## 功能说明

### 🔄 同步最新

从 `games.json` 记录的“最后更新日期”往后，循环拉取新帖子，直到追上站点最新内容。

- 单次点击最多处理 **3 批 × 100 篇 = 300 篇**帖子（约 50 个新游戏）
- 如果 3 批后仍未追上，会提示“请稍后再次点击”，下次从上次停下的位置继续
- 每批处理完立即写入 `games.json`，中途关闭页面不会丢进度

### 📥 同步历史

从 `games.json` 记录的“历史同步至”日期往前，拉取 **1 页 × 100 篇**历史帖子。

- 每次点一下，历史游标往前推 100 篇
- 每批完成立即落盘，可断点续传
- 拉到站点最早的内容时，会提示“已无更多历史数据”

**建议**：日常用“同步最新”即可，想要翻更早的历史时再手动点“同步历史”。

### ⭐ 收藏夹

分为两个阶段使用：

**海选**：滚动浏览时，悬浮任意卡片，面板底部有 **“⭐ 收藏”** 按钮。点击后：

- 按钮变为金色“⭐ 已收藏”，卡片右上角出现 ⭐ 角标
- 面板不关闭，卡片不移走，可以继续滚动收藏下一个
- 顶部“⭐ 收藏夹 (N)”的数字实时更新

**精选**：点击顶部“⭐ 收藏夹 (N)”进入收藏模式，只显示已收藏的游戏。此时：

- 同步、隐藏管理、月份导航、搜索框都隐藏，界面更简洁
- 悬浮卡片，点“打开页面 ↗”跳转 FitGirl 详情页查看完整信息
- 看完觉得不错 → 保留；觉得不合适 → 点“⭐ 已收藏”取消，卡片立即消失
- 顶部有“🗑 清空收藏”按钮，一键清空全部收藏（带确认）

**收藏与隐藏互斥**：收藏一个已隐藏的游戏会取消隐藏；隐藏一个已收藏的游戏会取消收藏。

**收藏夹按钮置灰**：收藏数为 0 时，按钮不可点击，鼠标悬浮提示“先收藏几个游戏吧”。

### 🚫 隐藏管理

- 鼠标悬浮任意卡片，面板底部有 **“🚫 隐藏”** 按钮，点击后该游戏永久隐藏
- 顶部 **“🚫 隐藏管理”** 可一次性恢复全部隐藏的游戏
- 隐藏状态存在 `games.json` 的每个游戏的 `hidden` 字段里，换机器也保留

### 🔍 搜索

- 支持标题（中文/英文）、标签、大小、日期的模糊匹配
- 中文输入法：拼音阶段不会触发搜索，选字完成后 150ms 自动搜索
- 英文输入：边打边搜，停手 150ms 后出结果
- 按回车可以跳过去抖，立即搜索
- 匹配结果超过 280 时，会提示“请添加更具体的关键词”，不会渲染
- 收藏模式下不支持搜索

### 📅 月份导航

- 顶部有年份下拉框 + 12 个月份胶囊，点击某个月份筛选“该月及更早的游戏”
- 月份胶囊按数据里实际有游戏的月份启用，无游戏的月份置灰
- 网格中按月份插入分隔条，滚动时顶部胶囊高亮自动跟随当前视口月份
- 向下滚时，月份分隔条进入顶部判定区 → 高亮切换；向上滚时，分隔条完全离开视口底部 → 高亮切回

### 其他

- **加载更多**：默认渲染 280 个游戏，滚动到底部可点“加载更多”继续追加
- **回到顶部**：向下滚动 400px 后，右下角出现 `↑` 按钮
- **悬浮面板**：鼠标停留 1 秒后弹出，显示截图/预告片/GIF、发布日期、大小、标签、收藏和隐藏按钮

## 数据文件

### `games.json` 结构

```json
{
  "version": 2,
  "lastCheck": "2026-10-18T16:00:00",
  "lastUpdate": "2026-10-18T07:00:04",
  "oldestSyncedDate": "2026-09-29T20:09:51",
  "games": [
    {
      "title": "Gears of War 4 – v14.4.0.2",
      "titleZh": "战争机器 4 – v14.4.0.2",
      "link": "https://fitgirl-repacks.site/gears-of-war-4/",
      "date": "2026-10-18T07:00:04",
      "size": "from 58.8 GB [Selective Download]",
      "tags": ["Action", "Shooter", "Cover-based", "Third-person", "3D"],
      "hidden": false,
      "favorite": false,
      "media": {
        "videoUrl": "https://video.fastly.steamstatic.com/.../microtrailer.webm",
        "gifUrl": null,
        "imgList": ["https://s01.riotpixels.net/.../xxx.jpg.240p.jpg"]
      }
    }
  ]
}
```

| 字段 | 用途 |
| --- | --- |
| `lastCheck` | 上次检查更新的时间（用于 12 小时自动更新节流） |
| `lastUpdate` | 已同步到的最新帖子日期（“同步最新”的游标） |
| `oldestSyncedDate` | 已同步到的最早帖子日期（“同步历史”的游标） |
| `games[].title` | 英文原始标题 |
| `games[].titleZh` | 中文标题（悬浮时翻译后写入） |
| `games[].hidden` | 是否隐藏 |
| `games[].favorite` | 是否收藏 |
| `games[].media` | 从帖子正文提取的视频/动图/截图 URL，提取后长期缓存 |

### 自动备份

每次双击 `start.bat` 时，如果目录里有 `games.json`，会**自动复制一份为 `games.json.bak`**（覆盖旧的备份，只保留一份）。

这意味着 `games.json.bak` 是**上次关闭时 `games.json` 的状态**。适合以下场景：

- 页面启动报错、读不了文件 → 用备份恢复
- 某次误操作把数据搞乱了 → 关闭页面、回滚到备份、重启

**注意**：它不是“每次写入前备份”。如果本次会话中连续操作多次、数据在某一刻损坏，备份还是上次启动时的内容。

### 数据安全建议

- **不要用记事本编辑 `games.json`**，尤其是页面还开着的时候——覆盖冲突会导致数据异常
- 修改前先手动复制一份 `games.json` 到别的位置

### 从备份恢复

当发现数据异常（页面报错、游戏数量不对、某次操作后数据回退）时：

1. 关闭页面和 `start.bat` 窗口
2. 把当前的 `games.json` 重命名为 `games.json.broken`（留个证据，也可直接删）
3. 把 `games.json.bak` 重命名为 `games.json`
4. 双击 `start.bat`
5. 页面点“继续使用”，确认数据恢复正常

## 常见问题

### 双击 `start.bat` 后黑窗口闪退

- 大概率是没装 Python。去 https://www.python.org/downloads/ 下载安装，安装时勾选“Add Python to PATH”
- 也可能是 8000 端口被占用（比如开了另一个 Python 服务）。关闭占用程序，或者修改 `start.bat` 里的端口号
- 或者是本地找不到 Chrome / Edge，且系统默认浏览器不支持 File System Access API

### 页面显示“浏览器不支持”

用的是 Firefox / Safari / 旧版 Chrome。换成 Chrome 86+ 或 Edge 86+ 打开 `http://localhost:8000/`。

### 页面显示“权限被拒绝”

在“继续使用”的授权弹窗里点了“拒绝”。关闭页面重新打开，重新点“继续使用”。

如果反复拒绝，可能是浏览器的站点设置里被禁用了。检查 `chrome://settings/content/filesystem`。

### 封面加载很慢或显示“图片加载失败”

图片托管在第三方图床（`imageban.ru`、`riotpixels.net`、`fastpic.ru`），性能取决于图床，不受本工具控制。

图片加载失败时会显示“悬浮看预览”，悬浮面板里会按顺序尝试多张图。如果某个游戏的封面永久失效（图床关站或 URL 变更），则无法提供图片预览效果。

### 翻译失败 / 标题还是英文

翻译使用 Google 免费接口，有频率限制。

翻译失败不会影响数据，悬浮时会自动重试。连续同步大量新游戏时，偶有失败是正常的，下次悬浮会补上。也可能谷歌翻译本身返回的仍是英文，这取决于接口。

### 换端口 / 换浏览器 / 清浏览器数据后，要我重新绑定文件

File System Access API 的文件句柄保存在浏览器的 IndexedDB 里，绑定关系是按域名 + 端口隔离的。以下情况会要求重新绑定：

- 从 `localhost:8000` 换到 `localhost:8080`
- 换了浏览器（Chrome → Edge）
- 清除了浏览器数据（包含“Cookie 及其他网站数据”）

数据本身不会丢，`games.json` 还在磁盘上。重新绑定同一个文件即可。

## 限制与已知问题

- **仅支持 Windows**：`start.bat` 是 Windows 批处理。Mac/Linux 用户可以手动运行 `python -m http.server 8000` 启动
- **仅支持 Chromium 内核**：Firefox、Safari 不支持 File System Access API
- **每次打开需授权一次**：浏览器安全策略，无法避免
- **不要同时打开多个标签页**：会互相覆盖数据
- **部分图床不可靠**：第三方图床可能失效、限流、防盗链
- **翻译依赖 Google 免费接口**：可能限流，失败时降级为英文
